# AFCS-Inspired Banking Financial Data Management & Reconciliation Project

**Type:** Independent learning / portfolio simulation  
**Technology:** Python, Pandas, Streamlit, SQLite, Plotly  
**Data:** Entirely synthetic; no customer or bank production data.

## Objective
Simulate selected financial-data-management concepts associated with Oracle Financial Services Accounting Foundation Cloud Service (AFCS): source data ingestion, data definition/mapping, data quality checks, transformation, event-to-account mapping, process monitoring, journal simulation and reconciliation.

This is NOT the Oracle AFCS product, an Oracle implementation, or a replica of Oracle's proprietary internals. It is an educational simulation based on publicly documented functional concepts.

## Run locally
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Create and activate a virtual environment.
4. Install dependencies: `pip install -r requirements.txt`
5. Run: `streamlit run app.py`

## Phase 1 contents
- Synthetic CASA, term-deposit and loan transactions.
- Synthetic source and GL balance snapshots.
- Reference data for branches, currencies and illustrative event-account mappings.
- Initial BRD, FRD, data mapping, DQ rules and UAT cases.

## Important assumptions
- The sample accounting mappings are illustrative training rules, not accounting advice or Oracle-seeded rules.
- This starter version uses simple deterministic checks and a simplified reconciliation key. A real bank implementation requires approved accounting policies, chart of accounts, data catalog definitions, security controls, audit trails and business sign-off.
- Reconciliation in this project is an educational comparison of synthetic source balances with synthetic GL balances.
